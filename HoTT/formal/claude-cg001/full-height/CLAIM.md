## 一句话

**对每个有限层，都有一个对象，在这一层宣布完成之后与单点一模一样，本身却不是单点。每个对象都在某个有限层被分开，可没有一个有限层分得开所有对象。要一次分开所有对象，就得把所有层一次交出，这正是 A。**

这与 C-444 深度轴上的“没有一个有限阶段够用”，是同一句话在高度轴上的形状。

## 用到的词（都在 `FullHeight.agda` 里定义或导入）

- **K n**：Eilenberg–MacLane 空间 K(ℤ, n)，cubical 库的 `EM ℤAbGroup n`。K 0 是 ℤ，K 1 是圆那样的东西，一般的 K n 只在第 n 层有一个 ℤ。
- **第 m 层的完成** `∥ A ∥ m`：A 的 m-截断，只留下第 m 层以下的信息（C-436 的规范完成）。
- **与单点一模一样**：完成之后可缩，即与 `∥ Unit ∥ m` 等价。
- **在第 n 层保住对象的完成** `KeepingCompletionAt n W`（C-436）：存在 ⟺ W 在第 n 层落定（C-443 (1)）。

## 命题全文：C-446

- **(1) 分不开**：
  - `pointAt`：`∥ K n ∥ (n+1)` 可缩（K n 是 n-连通的，库里的 `isConnectedEM`）；
  - `sameAsPointAt`：`∥ K n ∥ (n+1) ≃ ∥ Unit ∥ (n+1)`；
  - `pointAtLevel`：第 n 层同样如此。
- **(2) 分得开，价格恰是 n+2**：
  - `differAt`：`¬ (∥ K n ∥ (n+2) ≃ ∥ Unit ∥ (n+2))`；
  - `kPrice`：第 n+2 层的完成保得住 K n，第 n+1 层保不住（`kNotBelow`：K n 不在第 n+1 层）；
  - `unboundedPrice`：对每个 m，都有一个对象第 m 层保不住，价格没有上界。
- **(3) K n 本身不是单点**：`kNotPoint`（沿环路空间 Ω K(ℤ, n+1) ≃ K(ℤ, n) 一路降到 ℤ）。
- **(4) 没有一个有限层够用**：
  - `noFiniteLevelDetectsPoints`：不存在一个 m，使“第 m 层完成后可缩 ⟹ 本身可缩”对一切类型成立；
  - `noFiniteLevelSeparates`：不存在一个 m，使“第 m 层完成后等价 ⟹ 本身等价”对一切类型成立。
- **整体**：`qual-C446` 把 (1)–(4) 写成一个类型，并由一个项居留。

## 它在论证里的位置（身份分层）

- **〔机器已证〕**：上面的 (1)–(4)。
- **〔标准事实，不主张原创〕**：EM 空间是 (n−1)-连通的、n-截断的（库里写成 `isConnectedEM`、`hLevelEM`），环路空间降一阶（`Iso-EM-ΩEM+1`）。增量是排成“分不开 / 分得开 / 价格恰是 n+2 / 没有一个有限层够用”这张表，接到 C-436 的价格与元层特征方案 §7 第 5 条。
- **〔对应关系，是读法，不是定理〕**：
  - **同调代数**：K(ℤ, n) 是表示 n 次上同调的对象。Massey 积、Toda 括号这类高阶运算，是只在保留更高层结构时才看得见的信息。本包证的是它们背后最朴素的一句：对每个有限层，都有那一层看不见的差别。“在三角范畴（只留第 1 层）里宣布完成”看不见它们，是 C-440 的那一层；“全高度”就是本包。
  - **A 的位置**：每个对象都在某个有限层被分开（∀ 对象 ∃ 层），可没有一个层分开所有对象（¬ ∃ 层 ∀ 对象）。把这两句之间的鸿沟一步跨过，就是把所有层一次交出，即 A；这与 C-438 的判据一致。
- **〔史学假说，照实〕**：元层特征方案 §4 有一条 AI 判断：数学家在同调代数里看见过这个代价，并用保留更高结构的办法修补（dg 增强、A∞ 结构、稳定 ∞-范畴）。同方案的原话是：“这要回到原始文献核实（Verdier 的 TR3、Bondal–Kapranov 的增强、Lurie 的稳定 ∞-范畴导言），现在只是假说。”

## 禁止外推

- “第 m 层的完成”只指 m-截断及 C-436 意义下落到第 m 层、靠解码保住的完成，不是一切可设想的完成。
- (4) 说的是“没有一个固定的有限层对所有类型都够”，不是“某个对象在任何有限层都分不开”：每个 K n 在第 n+2 层就分开了。
