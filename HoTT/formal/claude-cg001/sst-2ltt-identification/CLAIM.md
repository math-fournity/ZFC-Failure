## 一句话

**按层的半单纯类型交到严格的一版、再经纤维取回，在第 1 层与第 2 层得到的就是原物：`SST 1`、`SST 2` 里的一条内层路径，对一切点族与边族。用的是单价性：一族类型沿一条路径相等，只要逐点等价。认同是内层路径，不按定义成立；严格的一版那一侧要认同就得是外层相等，内层单价性给不出。一般的 n 没做：从 n = 3 起，搬运壳要一条与取面相容的同伦，外层 UIP 管不到它。**

## 用到的词

- **按层的一版** `SST n`、**壳** `Sh`、**取面** `res`（C-450）；**交回** `toStrict`（C-452）；**经纤维取回** `Reverse.Lv`、**边界映射** `Reverse.bd`（C-453）。
- **内层路径** `≡`：两层类型论里内层（可纤）类型的相等，满足单价性；**外层相等** `≡ᵉ`：严格的相等，满足 UIP。`pathOfᵉ` 把外层相等变成内层路径，反过来不行。
- **单价性**：类型之间的等价给出路径（`ua`），沿它搬运就是那个等价（`uaβ`）。

## 命题全文：C-454

- **(1) 一族类型沿路径相等**：`famPathP p P Q e : PathP (λ i → p i → Type) P Q`，只要 `e : (a : A) → P a ≃ Q (transport p a)`。用 J 归到 p = refl，再用 `ua`。
- **(2) 投影后接等价的纤维**：`fiberAfterEquiv f c : fiber (λ z → f (fst z)) c ≃ B (invEq f c)`，对任意 `f : A ≃ C`、`B : A → Type`。
- **(3) n = 1**：对任意 `P : Unit → Type`，`One.ident P : Reverse.Lv (toStrict 1 (tt* , P)) 1 ≡ (tt* , P)`。经纤维的第 1 层是“点连同它的边界证明”，与 P 等价（`e₁`），用 `ua` 变成路径。
- **(4) n = 2**：对任意 `P : Unit → Type` 与 `E : Sh 1 (tt* , P) 2 → Type`，`Two.ident P E : Reverse.Lv (toStrict 2 ((tt* , P) , E)) 2 ≡ ((tt* , P) , E)`。证明用到：
  - 边界映射按定义就是“先投到壳，再逐个顶点换成纤维里的元素”（`Two.bdIs`，`refl`）；这个逐点替换是壳之间的等价（`ιEquiv`）；
  - 壳沿第 1 层的路径搬运，按定义逐个顶点算成 `uaβ`（`Two.trPath`）；
  - 于是经纤维的第 2 层在每个壳上与 E 等价（`Two.fib₂`，用 (2)），再用 (1)。
- **特例**：C-450、C-452 的两层例子 `pointsAndEdges P E` 来回一趟回到它自己（`twoExample`）。
- **整体**：`qual-C454` 是一个外层记录，把 (1)–(4) 放在一起，由一个项居留。

## 没做的（照实）

- **一般的 n**。本包只到 n = 2。从 n = 3 起，第 n 层的路径要建在第 n-1 层的路径之上，壳沿它搬运。壳里的边依赖它的两端：比较“搬运”与“逐点替换”的那条同伦，要与取面相容，这是一个 2-胞腔。壳是内层类型，不一定是集合，所以外层 UIP 管不到它；往上一层又要它自己的相干。n ≤ 2 时第 2 层的壳只含点，点的面都是 `tt`，这一步不出现。这是本包对障碍的分析（读法），不是不可能性的证明；两层类型论文献里 Reedy 纤维图与类型族两种写法的对应，本包没有核原文。
- **严格的一版那一侧**：要“认同为原物”就得是外层相等。内层单价性只给内层路径（`pathOfᵉ` 只从外层走到内层），所以 C-453 的逐层内层等价就是这个构造能给的；两层例子里外层相等按定义不成立（NEG-002）。这不是外层相等不可能成立的证明。

## 它在论证里的位置（身份分层）

- **〔机器已证〕**：上面的 (1)–(4) 与特例；两个负控制被拒。
- **〔标准事实，不主张原创〕**：单价性给出类型族沿路径的相等；纤维的全空间、投影的纤维。增量是把它接到 C-450–C-453 的构造上，在 n = 1、2 把来回认同为原物。
- **〔对应关系，是读法，不是定理〕**：
  - **有限阶段一致，从“等价”升到“相同”**：C-453 说每个有限阶段两边逐层等价；本包在 n ≤ 2 把它升成 `SST n` 里的相等，即同一个对象。C-450 说的“合成一座塔要一座桥”，仍是唯一剩下的差别。
  - **越往上，价格越要付在相干上**：n ≤ 2 不付相干，n = 3 起要付一个 2-胞腔，再往上一层又一层。这与 C-448、C-450 的“无穷相干”是同一件事在“认同”这一步的出现。
- **〔不是本包承接的〕**：一般的 n；严格的一版那一侧的外层认同；不推出 ZFC ⊢ ⊥，也不推出 ZFC-1 ⟹ B。

## 禁止外推

- 只证 n = 1、n = 2；不说对一切 n 两版作为类型相等。
- 认同是内层路径，不是外层相等；严格的一版那一侧只到内层等价。
- 对 n ≥ 3 障碍的说法是分析，不是定理。
