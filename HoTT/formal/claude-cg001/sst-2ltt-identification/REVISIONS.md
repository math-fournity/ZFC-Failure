# C-454 的更正（REVISIONS）

> `CLAIM.md` 已哈希进运行收据的源清单，不改；更正写在这里。

## 2026-10-23：一般的 n 不是“外层 UIP 管不到”

- **原写**（`CLAIM.md`“没做的”第一条）：从 n = 3 起，比较“搬运”与“逐点替换”的那条同伦要与取面相容，这是一个 2-胞腔；壳是内层类型，不一定是集合，所以外层 UIP 管不到它；往上一层又要它自己的相干。
- **为什么不成立**：
  - 那条同伦不用另外去证。把比较路径的自然性写成区间每一点上的外层相等（`(i : I) → … ≡ᵉ …`）。
  - 下一层的类型族路径取“比较映射在时刻 i 的纤维”，终点用 Glue 粘上目标族。每个面的路只由那个面自己的单纯形给出，面与面之间只用外层相等连起来。
  - 于是新的自然性只要 `apᵉ` 与外层 UIP（`substᵉ-uip`）。相干不会一层层往上要。
  - 原分析的错在把比较的自然性默认成内层路径之间的事。
- **新判据**：对一切外层 n，来回一趟在类型族这一层就是原物，由 C-455（`../sst-2ltt-identification-all/`）机器证出。严格的一版那一侧的说法（要外层相等，单价性给不出）不变。
