# C-453 的更正与后续（REVISIONS）

> `CLAIM.md` 已哈希进运行收据的源清单，不改；更正写在这里。

## 2026-10-23：“类型族这一层的认同”只说了一半

- **原写**（`CLAIM.md`“没做的”第一条）：在“类型族”这一层把 `Lv` 认同为原来的按层一版（作为 `SST n` 的元素相等），要用内层单价性把每层的等价变成路径，再沿它搬运壳。
- **为什么不够**：
  - 单价性是必要的，但不够。第 n 层的路径要建在第 n-1 层的路径之上，比较“沿路径搬运壳”与“逐点替换”的那条同伦要与取面相容，这是一个 2-胞腔。壳是内层类型，不一定是集合，外层 UIP 管不到它；往上一层又要它自己的相干。
  - 第 2 层的壳只含点，点的面都是 `tt`，这一步不出现，所以 n ≤ 2 只靠单价性就够。
  - 严格的一版那一侧要“认同为原物”就得是外层相等，内层单价性只给内层路径，给不出。
- **现在的状态**：C-454（`../sst-2ltt-identification/`）在 n = 1、2 把来回认同为原物；一般的 n 没做，障碍如上（分析，不是不可能性证明）。

## 2026-10-23（同日再更正）：上面那条障碍分析也不成立

- 上一节写的“外层 UIP 管不到，往上一层又要一层相干”是错的。把比较路径的自然性写成区间每一点上的外层相等，相干就仍由外层 UIP 收住。
- C-455（`../sst-2ltt-identification-all/`）对一切外层 n 证出来回在类型族这一层就是原物，三层更正写在 `../sst-2ltt-identification/REVISIONS.md`。
- 所以本包 `CLAIM.md`“没做的”第一条，现在应读作：按层的一版那一侧，单价性加上逐点的外层自然性就够，C-455 已做；严格的一版那一侧要外层相等，单价性给不出，不变。
