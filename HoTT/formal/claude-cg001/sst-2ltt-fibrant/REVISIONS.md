# C-450 的更正记录

`CLAIM.md` 进了源清单（已哈希），不改；更正写在这里。

## 2026-10-22（会话 a15f4b3b）：“全空间的取面”其实已经有了

- **原写法**（`CLAIM.md` “仍没做到的”第三条）：“只给了壳上的取面；单纯形全空间上的面映射可由它得到，本包没写出。”
- **为什么不成立**：k ≤ n 时，`Sh n Y k` 含有 k 顶点单纯形每一个不超过 n 个顶点的面上的数据，其中包括顶面本身（恒等嵌入 `idᵗ k`），所以它就是 k 个顶点的单纯形（连同它所有的面）的全空间；`res n Y` 就是全空间上的取面，`resId`、`resComp` 就是它的严格函子律。
- **新写法**：本包已经给出单纯形全空间上的取面（k ≤ n 时的 `Sh n Y k` 与 `res`）。内核实跑见 C-452（`../sst-2ltt-correspondence/`）：两层的例子里，第 2 层的全空间就是边连同两端，从一条边取面得到它的端点。

## 2026-10-22（会话 a15f4b3b）：“两版之间的关系”做了一个方向

- **原写法**（`CLAIM.md` “仍没做到的”第二条）：本包的 `SST n` 与 C-448 的 `SSTˢ` 之间的对应没有建。
- **现状**：C-452 给出一个方向，`toStrict : (n : ℕˢ) → SST n → SSTˢ`（k 个顶点的单纯形取作 `Sh n Y k`，高于 n 维的是余骨架）。反方向（经纤维）与两个来回是等价仍没做。
