## 一句话

**两层类型论里，对每个外层自然数 n，“只有前 n 层的半单纯类型”的全体是一个内层类型 `SST n`。第 m+1 层是建在“m+1 个顶点的单纯形的边界壳”上的类型族；壳和取面都按外层归纳给出；取面的单位律与复合律是外层严格相等，对一切 n 都证出；在具体的面上，这些相干的证明按定义就是 refl，一分不付。全部层合在一起的那座塔只作为外层对象存在，直接写成内层类型被拒绝；给一座从内层自然数到外层自然数的桥，塔才成为内层类型，而这座桥按内层递归写不出。**

## 用到的词（都在 `SemisimplicialTwoLevel.agda` 里定义或导入）

- **外层自然数** `ℕˢ`、**外层严格相等** `_≡ˢ_`（C-442）；**载体是内层类型的外层相等** `_≡ᵉ_`、外层 UIP `uipᵉ`、**子序列嵌入** `Th j k`（把 j 个顶点按序嵌进 k 个顶点）与复合 `_∘ᵗ_`（C-448）。
- **面上的积** `ΠTh m k P`：对 k 个顶点的单纯形的每个 m 顶点面各取一个 `P` 的元素，用外层递归展开成内层的有限元组；`appTh`、`lamTh` 是取分量与打包。
- **前 n 层的半单纯类型** `SST n`（内层，`Type₁`）：`SST 0` 是单点；`SST (n+1)` 是一个 `X : SST n` 加上建在“n+1 个顶点的单纯形的边界壳”上的类型族。
- **壳** `Sh n X k`：X 在 k 个顶点的单纯形上的前 n 层数据：每个不超过 n 个顶点的面上一个元素，面与面在公共部分对上。
- **取面** `res n X T`：沿嵌入 `T : Th j k`，把 k 顶点单纯形上的壳限制到 j 顶点的面上。
- **塔** `SSTω`（外层记录）：每个外层 n 一层，每层忘掉最高层就是前一层。
- **桥**：一个映射 `toOuter : ℕ → ℕˢ`（从内层自然数到外层自然数），满足 `toOuter (suc n) ≡ˢ sucˢ (toOuter n)`。

## 命题全文：C-450

- **(1) 每个外层 n，一个内层类型**：`SST : ℕˢ → Type₁`，`Sh n X k : Type`。
- **(2) 取面**：`res : (n : ℕˢ) (X : SST n) → Th j k → Sh n X k → Sh n X j`，对一切 n 由外层归纳给出。
- **(3) 严格的函子律，对一切 n**：
  - `resId : res n X (idᵗ k) s ≡ᵉ s`；
  - `resComp : res n X (T ∘ᵗ S) s ≡ᵉ res n X S (res n X T s)`。
  - 证明里要把面上的数据沿外层相等搬运；端点相同的两条外层相等给出同一个搬运，靠的是外层 UIP（`substᵉ-uip`）。
- **(4) 内核实跑**（都是 `reflᵉ`）：
  - `points`：`SST 1` 就是一个点的类型；
  - `edgeShell`：一条边的壳就是两个点；`edgeEnds`：沿两个面 ε₀、ε₁ 取出的正是这两个点（ε₀ 去掉第 0 个顶点，留下第 1 个）；
  - `triangleShell`：三角形的壳就是三个点加三条边 01、02、12，每条边的两端正是它的两个顶点；
  - 例子：`pointsAndEdges`（两层：点与边）、`pointsEdgesTriangles`（三层：点、边与“三条边围成的三角形族”）。
- **(5) 相干的相干是事实；具体的面上相干就是 refl**：
  - `resCompFlat`：复合律的任何两条证明都相等；
  - `freeComp₂`、`freeComp₃`、`freeId₃`、`freeComp₄`：n = 2、3、4 的四个具体实例（X 与壳任意），复合律与单位律的证明按定义就是 `reflᵉ`。
- **(6) 塔是外层对象**：`SSTω` 是外层记录；`codiscreteω P : SSTω`（点是 P，更高的层全是 Unit）是一个例子。
- **(7) 有桥，塔就是内层类型**：在模块 `Bridge toOuter toOuterSuc` 里，
  - `towerInner : Type₁`：按内层自然数编号的各层，加上“忘掉最高层就是前一层”的内层路径；
  - `fromω : SSTω → towerInner`：每座外层的塔都给出一座内层的塔。
- **整体**：`qual-C450` 是一个外层记录，把 (1)–(7) 放在一起，由一个项居留。

## 与 C-448 阻塞的关系（照实）

- **C-448 写的阻塞**：要的机制是有限逆范畴上 Reedy 纤维的图的极限可纤；Agda 的 `--two-level` 没有“可纤”这个谓词，要从头建。
- **本包的做法**：不建一般的可纤性谓词，而是把匹配对象（壳）直接写成内层类型：有限个面上的积用外层递归展开成内层的元组，于是每个 `SST n` 按构造就是内层类型。思路是 Herbelin（2015）给半单纯类型的构造加外层的 UIP。“对外层的 n 构造前 n 层的半单纯类型”正是 Annenkov–Capriotti–Kraus–Sattler 两层类型论论文（arXiv 1705.03307）摘要里举的应用（摘要读于 2026-10-21，正文未读）。不主张原创。
- **所以**：C-448 没做到的那一半，即对每个外层 n 把前 n 层的半单纯类型全体做成一个内层类型，本包做到了。
- **仍没做到的**：
  - **不加桥的塔的内层版本**：直接写被拒（NEG-001）。上面那篇论文的摘要说，像 Voevodsky 的 HTS 那样让自然数表现得像外部自然数的公理，在两层类型论里可以取为“内层与外层的自然数同构”。(7) 的桥只要求一个与后继相容的映射，比同构弱。它与论文里的公理及其推论的确切关系，正文未读，未核。
  - **两版之间的关系**：本包的 `SST n`（类型族的一版）与 C-448 的 `SSTˢ`（严格预层的一版）之间的对应没有建。
  - **全空间的取面**：只给了壳上的取面；单纯形全空间上的面映射可由它得到，本包没写出。
  - 在 HoTT 内部（一层）对一切 n 统一定义半单纯类型：据 AI 的文献印象至今是公开问题，本包不碰。

## 它在论证里的位置（身份分层）

- **〔机器已证〕**：上面的 (1)–(7)；两个负控制被拒；C-442 的 NEG-002（桥按内层递归写不出）已被拒。
- **〔标准事实，不主张原创〕**：构造思路（Herbelin 2015；两层类型论的应用）；外层 UIP；子序列嵌入构成 Δ₊。
- **〔对应关系，是读法，不是定理〕**：
  - **每一层都付得起，合成一座塔要一座桥**：对每个具体的 n，`SST n` 是内层类型，它的相干在具体的面上按定义就是 refl；全部层合成的塔只在外层存在；要它成为内层的一个对象，要一座从内层自然数到外层自然数的桥，桥按内层递归写不出。
  - **A 的位置**：研究发起人对 A 的定义是“A就是一个无限的步骤才能到达，从而存在的结果，当作已经存在的结果，参与运算。”（核心认知）。按这个定义读：每个有限阶段都是付清了的构造；把那座塔当作一个已经存在的内层对象来用，就是把“无限步才到的结果”当作已经存在。本包把这一步要的东西定到了一个具体的映射上：把内层（有结构的一层）的自然数逐个当作外层（相同只是事实的一层）的、已经完成的自然数来用。
  - **具体实例化简后是普通的 HoTT 类型**：`triangleShell` 这类实例按定义化简后只剩 Σ、×、Unit 与 Type。对一切具体的 n 都如此，是按构造的读法，没有机器检查一个一般命题；按 n 统一生成它们的那个函数在外层。
  - **与 C-448、C-442 是同一个读法**：外层（相同是事实）里，“所有层一次交出”免费；要它成为内层的一个对象，就要另交。
- **〔不是本包承接的〕**：上面“仍没做到的”四条；不推出 ZFC ⊢ ⊥，也不推出 ZFC-1 ⟹ B。

## 禁止外推

- 不能说“HoTT 里定义出了半单纯类型”：统一的定义用了外层自然数与外层相等；每个具体的 `SST n` 是内层类型，全部层合起来的塔不是（除非给桥）。
- NEG-001 只说明直接写法被拒，不证明塔的内层版本在任何假设下都做不出；(7) 恰好说明加一座桥就做得出。
- 桥是模块参数：(7) 是“若有桥则……”，不断言桥存在，也不断言它不存在（它在哪些模型里存在，本包不讨论）。
- (5) 的“相干就是 refl”只在四个具体实例上机器检查过；变量的嵌入上两端不按定义相等，这句话本身写不出来。
- 只在 macOS 捕获与重放。
