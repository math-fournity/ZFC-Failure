## 一句话

**一个二进制小数等于 0，当且仅当它的每一位都是 0。所以“这个实数是不是 0”就是“这个数字流是不是处处为 0”，C-441 关于数字流的结论原样落到实数上：任何有限阶段都确认不了它是 0；要一次判定所有这样的实数是不是 0，就等于 WLPO。**

## 用到的词（都在 `RealDepth.lean` 里定义）

- **数字流** `s : ℕ → Bool`：二进制小数 0.s₀s₁s₂… 的各位。
- **第 n 位的贡献** `digit s n`：是 1 时为 (1/2)^(n+1)，是 0 时为 0。
- **数字流表示的实数** `val s = ∑' n, digit s n`：Mathlib 的 `ℝ` 里的一个数，落在 [0, 1]。
- **只在第 n 位是 1** `onlyAt n`；**0.0111…** `tailOnes`。
- **WLPO 的流形式** `WLPO`：对每个数字流，判定它是不是处处为 0。

## 命题全文：C-447

- **(1) 桥接引理** `val_eq_zero_iff`：对任意数字流 s，`val s = 0 ↔ ∀ n, s n = false`。
- **(2) 有限阶段确认不了**：
  - `noFiniteStageConfirms`：对每个 n，有一个流（`onlyAt n`）前 n 位都是 0、前 n 位的部分和是 0，`val` 却不是 0；
  - `noStageSuffices`：不存在 N，使“前 N 位都是 0 ⟹ 实数是 0”对一切数字流成立。
- **(3) 一次答完** `zeroTest_iff_WLPO`：`(∀ s, val s = 0 ∨ val s ≠ 0) ↔ WLPO`。
- **(4) 边界** `notInjective`：存在两个不同的流表示同一个实数：`val (onlyAt 0) = 1/2 = val tailOnes`（0.1000… 与 0.0111…）。
- **整体**：`qual_C447` 把 (1)–(4) 写成一个命题，`#print axioms` 只报三条标准公理。

## 它在论证里的位置（身份分层）

- **〔机器已证〕**：上面的 (1)–(4)。
- **〔标准事实，不主张原创〕**：非负项级数和为 0 当且仅当每一项为 0；二进制展开不唯一（0.0111… = 0.1000…）。增量是把它们接到 C-441 的数字流结论与 H 深化的深度轴上。
- **〔对应关系，是读法，不是定理〕**：
  - **深度轴落到实数**：C-441 说“相同”在深度上问不完。实数的“等于 0”就是一个这样的问题：每多看一位，就多确认一位是 0，可永远确认不完。经典分析用排中律（A 的一种形式）一次答完，所以“lim sₙ = L？”是一个现成的命题，这正是 H 深化 §4.1 说的“终局问题”。
  - **为什么只说“等于 0”**：一般的“x = y”不是数字流相等（(4)），要看 x − y 是不是 0，那需要带符号的表示。本包只证“等于 0”这一处桥，GOAL 要的也是这一处。
  - **与研究发起人的芝诺**：KC-000065 说芝诺从第一天起就是可计算性问题，每次走剩下的一半，永远走不完。“0.000… 是不是 0”与“剩下的那一半走没走完”是同一种逐位追问，这是读法。
- **〔不是本包承接的〕**：
  - Mathlib 的 `ℝ` 是经典构造（柯西序列的商），本包不在构造性实数上做；(3) 在 Lean 里两边都成立，定理说的是二者等价，不是哪一边可构造。构造性的那一面由 C-441（Cubical，WLPO 不可证）承担；
  - 不推出 ZFC ⊢ ⊥，也不推出 ZFC-1 ⟹ B。
