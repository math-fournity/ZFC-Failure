## 一句话

**单价 1-范畴：做了，即 C-449。单价范畴的全体落在第 4 层，追问最迟第 3 问停，第 4 层的完成保得住它，“有上限则藏”在范畴上也对。Rzk：这一轮不做。它能声明自然数与圆，但单价性不内建；要在 Rzk 里让 A 显形，就得先把单价性写成公设，那样得到的只是 HoTT 结果在公设下的复述，不是独立的新实例。**

> **2026-10-23 更新**：Rzk 这一半做了，即 C-456（`HoTT/formal/claude-cg001/two-causes-rzk/`，证据索引 §83），身份是“在单价性公设下”。§2.2 的成本判断与“要写出所有高度的见证”有两处不成立，见 §4。

## 1. 单价 1-范畴：做（C-449）

- **可行性实查**：cubical 0.9 的 `Cubical/Categories/Equivalence/WeakEquivalence.agda` 第 195 行已有 `is2GroupoidUnivalentCategory : is2Groupoid (Σ (Category ℓC ℓC') isUnivalent)`，靠的是同一文件里的范畴结构同一原理 `WeakEquivalence≃Path`。
  - **自我推翻**：做之前我的工作假设是“cubical 0.9 没有范畴的结构同一原理，做这一行要几个小时”。查源码后发现它已在库里，代价很小，所以决定做。
- **结果**（`HoTT/formal/claude-cg001/univalent-categories/`，证据索引 §76）：
  - 单价范畴的全体（对象在 `Type₁`、态射在 `Type₀`；集合的范畴、群的范畴都是成员）落在第 4 层；
  - 同一个逐层追问程序，任何判定器两步之内答出，答案是对的；
  - 第 4 层的完成保得住它；宇宙永不停、任何有限层都保不住。
- **没做到的**：方案预测“第 3 问停”，C-449 只证“最迟第 3 问”。恰在第 3 问，要证单价范畴的全体不是群胚：要有一个单价范畴，它的某个自等价有非平凡的自然自同构（候选例子：ℤ-torsor 范畴的恒等函子，其自然自同构是 ℤ；这是 AI 的数学判断，未证）。这要另建一套例子，这一轮不做。“有上限则藏”这一面不依赖它。
- **2026-10-22 更新**：恰在第 3 问停已由 C-451 证出（`HoTT/formal/claude-cg001/univalent-categories-exact/`，证据索引 §78）。见证用的不是 ℤ-torsor 的范畴，而是圆的路径范畴（作为群胚两者都是 Bℤ），因为它不必另建：群胚的路径范畴是单价范畴，宇宙里圆到自身的认同不构成集合（rotLoop ≠ refl），前者是后者的收缩，所以单价范畴的全体不是群胚。

## 2. Rzk：这一轮不做

### 2.1 探针（`G10-探针/`，`bash run_probes.sh` 重跑，Rzk 0.11.3）

| 探针 | 测什么 | 结果 |
|---|---|---|
| `p1-no-builtin-nat.rzk` | 有没有内建的自然数 | 没有：`undefined variable: Nat` |
| `p2-data-point-constructors.rzk` | `#data` 能不能声明 ℕ | 能 |
| `p3a-path-constructor-short-form.rzk` | 圆的路径构造子，写成 `loop : base = base` | 被拒，但报错说路径构造子**支持**，要写明载体（`l =_{S1} r`） |
| `p3b-circle-as-hit.rzk` | 写明载体：`loop : base =_{S1} base` | 能：Rzk 有高阶归纳类型 |
| `p4-postulate-needed.rzk` | 能不能写公设 | 能（`#postulate`） |
| `p5-no-builtin-ua.rzk` | 有没有内建的单价性（按常用名 `ua`） | 没有：`undefined variable: ua` |

**自我推翻**：探针 3a 之前，我的工作假设是“Rzk 没有高阶归纳类型”。报错信息本身推翻了它，3b 验证了。所以“不做”的理由不能写成“做不到”。

探针 5 只证明没有叫 `ua` 的内置，不证明 Rzk 的内核里没有任何单价性原理。这与本仓库已有的 Rzk 包一致：它们都没有引入单价性（`grep '#postulate\|#assume'` 在 `HoTT/formal/claude-cg001/*/*.rzk` 里无命中）。

### 2.2 理由

- **决定性的成分要靠公设**：C-430 证明暴露 A 要两个成因，单价性与所有高度一次交出。在 Rzk 里，自然数与圆都能声明，可是“圆的回路不是 refl”“宇宙不落在任何有限层”这类事实要靠单价性来证。单价性不内建，就只能写成公设。那样得到的“单纯类型论暴露 A”，是 HoTT 的 C-430、C-438 在公设下重跑一遍，不是一个独立的新实例。
- **单纯类型论自己的特点不在这条轴上**：Rzk 的特色是有向箭头（hom、Segal、Rezk），判据量的是高度。本仓库已经在有向那条线上用过 Rzk（C-57、C-58、`directed-native`）。
- **成本与收益**：要移植 C-77 的追问程序（自然数、延迟结构）、写出所有高度的见证（高阶圆或 EM 空间的高阶归纳类型），再加单价性公设。估计至少一天，收益只是“第二个内核在公设下确认同一件事”。

### 2.3 什么时候值得再做

- 研究发起人想要“第二个内核独立确认高度轴的结果”时：用公设引入单价性，把 C-77 的程序与 C-430 的两个成因移到 Rzk 里重跑。结论的身份要写成“在单价性公设下”。
- 或者 Rzk 将来内建单价性（例如出现 Glue 类型）时，重测探针 5，这件事就有了独立的证据价值。

## 4. 2026-10-23 更新：Rzk 这一半做了（C-456）

> Claude Code 桌面会话 a15f4b3b（接手会话 91beaf35）。起因：研究发起人 2026-10-23“我授权了，你全部做完。”，目标“所有的后续`GN`，全部完成并推送”之下，目标的检查方把 Rzk 这一半列为未完成。按 §2.3 的第一种情形做。

### 4.1 结果

- C-456（`HoTT/formal/claude-cg001/two-causes-rzk/`，证据索引 §83）：在 Rzk 0.11.3 里，以单价性为前提，C-77 的追问程序 (a)–(e) 与 C-430 的两个成因 (1)–(4) 逐条被第二个内核接受，见证（宇宙、汇集、编号收集、成对收集）与三次内核实跑也在；四个负控制被拒；五个运行都精确重放。
- 身份：**在单价性公设下**，按 §2.3 的要求。
- 同日 C-457（`HoTT/formal/claude-cg001/judges-gatherings-rzk/`，证据索引 §84）补齐 C-456 照实写明没做的三项：C-78 (b)（判定器唯一）、C-78 (d)（另一个问题）、C-79 (b) 对一切 n（下界另以一族有上限的见证为参数）。至此 C-77、C-78、C-79 与 C-430 在 Rzk 里都已重跑。

### 4.2 推翻了什么（三层）

1. **单价性怎么进来**
   - 原判据：“用公设引入单价性”。
   - 为什么不照做：本仓库的 Rzk 捕获工具与核验器都拒绝 `#postulate`；而且公设一旦写错，整个文件都跟着空转。
   - 新做法：单价性作为每条用到它的定理的参数 `univ`。结论的身份不变（“单价性 ⟹ …”），收据仍无公理；哪条定理不带这个参数，内核就已经证明它不用单价性（C-77 的程序事实、C-430 的 (3) 与 (4) 的后半）。
2. **所有高度的见证**
   - 原判据（§2.2 的成本一条）：“写出所有高度的见证（高阶圆或 EM 空间的高阶归纳类型）”，只是贵。
   - 为什么不成立：Rzk 0.11.3 根本不支持路径之间的路径构造子。包内探针 `probes/HigherPathConstructor.rzk` 声明二维球面，报错原文：“higher path constructors are not supported yet”。所以这些见证在 Rzk 里写不出来，不是贵。
   - 新判据：A 的见证作为第二个参数 `K : EveryHeight`，只进宇宙、编号收集、成对收集三处；一般定理不带。在 Rzk 里，两个成因都只能从外面递进来。
3. **成本**
   - 原判据：“估计至少一天”。
   - 实际：一个会话内写完，约 1900 行，内核检查 1.7 秒。贵的是 HoTT 底座（函数外延性、h-层的封闭性、回路空间），Rzk 没有可用的库，要从数据类型写起。“等价的纤维可缩”本要一段半伴随的路径代数，用单价性做等价归纳就绕开了。

### 4.3 仍然成立的

- §2.2 第一条：不内建单价性时，这里得到的仍是 HoTT 结果在单价性前提下的复述，不是独立的新实例。新增的是“第二个独立实现的内核逐步接受了同一套推导”。
- Rzk 有 `U : U`（包内探针 `probes/UniverseInUniverse.rzk`）：确认的是推导，不是第二个基础的相容性。
- §2.3 的第二种情形（Rzk 将来内建单价性、出现 Glue 类型）仍是这件事有独立证据价值的条件，届时重测探针 5。
