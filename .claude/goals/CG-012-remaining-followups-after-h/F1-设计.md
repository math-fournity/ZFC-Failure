## 1. 定义

- `ι n = [ pos 1 / 1+ n ]`（1/(n+1)）。
- `within ε a b = (a − b ≤ ε) × (b − a ≤ ε)`。
- `BReal`：`seq : ℕ → ℚ`，`reg : ∀ m n → within (ι m + ι n) (seq m) (seq n)`。
- `x ≈ y = ∀ n → within (ι n + ι n) (seq x n) (seq y n)`；`ℝ = BReal / _≈_`（集合商）。传递性要阿基米德引理：`(∀ m → a ≤ c + [pos K / 1+ m]) → a ≤ c`（代表元上：若 p·t > s·r，取 m+1 = K·t·r + 1 得矛盾）。
- 实数列 `X : ℕ → BReal`：`Le x y = ∀ j → seq x j ≤ seq y j + (ι j + ι j)`；`MonoR X = ∀ m n → m ≤ n → Le (X m) (X n)`；`BoundedR X = Σ M : ℕ, ∀ n j → within (pos M) (seq (X n) j) 0`（界取自然数，避开从有理数取整数上界）。
- `CloseR k x y = ∀ j → within (ι k + (ι j + ι j)) (seq x j) (seq y j)`。
- `BMCRmod`：`∀ X → MonoR X → BoundedR X → Σ[ N ∈ (ℕ → ℕ) ] ∀ k m → N k ≤ m → CloseR k (X m) (X (N k))`。
- `BMCRlim`：`∀ X → MonoR X → BoundedR X → Σ[ ℓ ∈ BReal ] ∀ k → Σ[ N ∈ ℕ ] ∀ m → N ≤ m → CloseR k (X m) ℓ`。

## 2. 证明

- **BMCRmod → LPO**：单调开关 s 的 0/1 常数实数列；精度 1/2（k = 1），在 j = 7（ι 7 = 1/8）读出：两位不同则 1 ≤ 1/2 + 1/4，矛盾；于是 s 在 N 1 落定，得 `LimBit`，再用 `lpoOfLimBit`。
- **LPO → BMCRmod**：精度 k，取 J = 8k+7（4ι J = ι(2k+1)），δ = ι(2k+1)，q n = seq (X n) J。从 N 出发，对开关 n ↦ [q (N+n) > q N + δ] 用 LPO：
  - 左支（从不涨过 δ）：m ≥ N 时 q m ≤ q N + δ，又 q m ≥ q N − 2ι J（单调），于是 CloseR k (X m) (X N)，因为 2ι j + δ + 4ι J ≤ ι k + 2ι j。
  - 右支（在 N+n 涨过 δ）：换到 N + n 再来。
  - 燃料 F = 4M(k+1) + 1；不变式 M < q N + fuel·δ（初始由 q 0 ≥ −M 与 F·δ > 2M）；燃料为 0 时不变式与 q N ≤ M 矛盾，所以不会走到。N(k) 取迭代的结果。
- **BMCRmod → BMCRlim（完备性）**：P j = max_{t ≤ j} N(8t+7)（单调），ℓ j = seq (X (P j)) (8j+7)。正则性：i ≤ j 时 |ℓ i − ℓ j| ≤ 3/(8(i+1)) + 5/(8(j+1))；i > j 对称。收敛：n ≥ P k 时 CloseR k (X n) ℓ。
- **BMCRlim → BMCRmod?** 不需要；`BMCRlim → LPO` 经“极限 ⟹ 柯西 ⟹ 开关落定”直接证。

## 3. 负控制候选

- 极限的正则性指标取 j 而不是 8j+7（界不够，内核拒）——或更简单的定义层负控制。
