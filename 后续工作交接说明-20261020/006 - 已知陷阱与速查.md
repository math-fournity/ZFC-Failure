## 2. 机械坑（照抄即可）

| 坑 | 正解 |
|---|---|
| 本 repo 的 v2 shard index 要求 index 与目录**同名同 stem** | `dev-docs/X.md` + `dev-docs/X/` |
| shard 用 `<!-- governance-shard:v2 -->` HTML 注释，不是 YAML frontmatter | 见任一分片首 4 行 |
| 文件名 topic 必须与索引链接标题**逐字相同** | 包括标点 |
| `topical` 模式 `append_target` 必须是 `-` | `sequential` 模式才填目标分片 |
| `git commit -F <file>` 与 `--only` 冲突 | 用 `git commit --only -F <file> -- <paths>` |
| heredoc 内含反引号被 zsh 解析炸掉 | 写 Python 用 `chr(96)` 拼反引号 |
| `verify_formal_proof_run.py` 的参数 | 是 `--run-dir`，**不是** `--run` |
| `MEMORY/001` 是 `MUTABLE`，绕过事务直改会让 runtime 拒绝加载 | 走 checkpoint 事务 |
| session 目录第一层文件在 checkpoint 前必须不存在 | payload 里带 `text` |
| record run 目录已存在 → capture 脚本 `REFUSE_OVERWRITE` | 设计如此，别手工删 |
