# 规则、工具与复现

## 1. 文档解析分派表（研究发起人直接问过，规则先于表）

**规则**：
1. 通道由"这本书扮演什么角色"决定，不由页数决定。
   - 要"读过全文 / 检索全册 / 证明某词零命中" ⟹ **MinerU**；
   - 要"这一句作数" ⟹ **视觉审计**，且**只审承载那一句的页**。
2. **规模上限是硬约束**：视觉审计 ≤ 引用句所在页（通常 ≤ 25 页）。
   迄今唯一全审的 PDF 是 **zermelo 1908（21 页）**——上限实例，不是常态。
3. >200 页一律 `~/.agents/skills/mineru/scripts/parse_large.py` 按页范围分片请求，
   **禁止物理拆分 PDF**。

**完整逐册表**在
`docs/文档解析与视觉审计/MinerU-视觉审计-执行/README.md` §E（2026-10-20 追加）。

**已知失败模式**：柯西 1821 整册 604 页 21 片全败
（首片 `remote_timeout`，其余 `quality_tier_unavailable`）。
→ 改用小范围多次定向请求，不重试整册、不拆源文件。失败账本留在
`docs/芝诺解决考古/搜索原始响应-20261017/zeno-溯源/candidates/mineru_md/_failed-run-ledger-20261018.tsv`。

**一句话**：**MinerU 负责"读过"，视觉审计负责"这一句作数"。**

## 2. 机械化比对纪律（本轮最重要的工程规则）

任何"逐字一致 / 命中 / 逐字确定"的书面声明，**必须附可重跑的匹配命令与口径**。

口径（Z01–Z06 一致）：

~~~bash
python3 - <<'PY'
import re, unicodedata
def norm(s):
    s = unicodedata.normalize("NFKD", s)
    return re.sub(r"[^A-Za-z0-9]", "", s).lower()
PY
~~~

- 中文/英文：去空白、去变音符号、去标点后小写，子串包含判定；
- 希腊文：去空白 + 去变音符号（`re.sub(r'[^Α-ωα-ω]','')` 一类）；
- **HTML 源必须先剥标签 + 解实体**，否则标签字母混入匹配串造成假阴性（本轮实例）；
- 行号 locator 一律脚本算，禁止目测。
