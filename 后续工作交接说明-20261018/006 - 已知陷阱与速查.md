# 已知陷阱与速查

## 1. 这十天新踩的坑（按"会不会再犯"排序）

### 1.1 【最易再犯】凭印象写"逐字一致"

这十天栽了三次（Z01 的 S2 噪声、B3 的 T4 LaTeX、Z02 的来源混用）。
**每次都是机械比对抓到，肉眼都放过。**

**对策**：把 §1.2 的三种口径当成写字前的必需步骤，不是事后补的装饰。
写完一条"一致"声明，立刻问自己：匹配命令是什么？换了严格口径还成立吗？

### 1.2 【最易再犯】凭训练记忆给 URL

本轮实际发生：我以为 Russell 1914 在 Gutenberg #7369，抓下来发现是 John Masefield 的 *Jim Davis*。
换检索才找到 #37090。

**对策**：URL 只从检索结果或元数据页取；抓下来第一件事是核 `<title>` 与 Author 字段，
再核关键词命中数（零命中的页面要确认不是 404 或空壳）。

### 1.3 整册 parse_large 可能全败

S2 柯西 604 页 21 片全败（`remote_timeout` + `quality_tier_unavailable`）。
**不是文件问题，也不是本地问题**——小范围 `--pages 145-147` 同文件一次成功。

**对策**：先试小范围定向页；要整册再 `parse_large.py`，失败了不要反复重试，
登记失败账本（本 repo 的样例：`_failed-run-ledger-20261018.tsv`）。

### 1.4 S2（PNI-1898）的文本层质量明显差

`somme`→`s°mme`、`plus`→`Pfiis`、`de la série`→`je [a série`。
引用柯西时**以 MinerU 或 S1 pdftotext 为源**，S2 只作第三本互证。

### 1.5 Cubical `Rationals` 的 `_-_` 无 fixity 声明

（承接自 09-17 金形态线，仍然有效）`r·r-2r` 会静默解析成 `r·(r-2r)`，必须显式括号。

### 1.6 archive.org 主流大学教科书是借阅制

Stewart/Thomas/Larson 均不可直接下载全文。检索到条目 ≠ 能读。
**不要把"检索到"写成"已读"**，身份一律 `SOURCE_REPORTED` 或更低。

### 1.7 旧会话的"已证"主张可能是乐观描述

交接文档里"已证/已完成"的字样可能对应未编译的源码。任何"已证"都必须核对：
对应 `.lean` 能被 `devbuild_ns.py` 编译（exit 0、无 `sorry`）且有正式收据。

## 4. 人话词汇表（给不是读形式化长大的读者）

| 词 | 一句话 |
|---|---|
| **ZFC** | 现代数学最常用的地基公理系统（集合论） |
| **HoTT** | 同伦类型论，另一套数学地基；本 repo 的"问题"出在它的宇宙上 |
| **ASK / Q** | 在承认一个结果"已经有了"之前，先问产生它的计算能不能做完、停不停得下来。ZFC 缺的就是这一问 |
| **A / P** | 同一个动作两个名字：把无限步才能到达的结果，当作已经存在的结果拿来运算 |
| **ZFC-1** | ZFC + A。研究发起人的说法：数学社区实际用的 ZFC 已经不是原生的 ZFC |
| **B** | main 分支上找到的 HoTT 的问题："这两个东西是不是同一个"在宇宙里一层层永远问不完 |
| **单价性** | HoTT 招牌原则"同构即同一"；它让"是不是同一个"可以一层层问下去 |
| **截断** | 把"相同"的多种方式压成一种；它改变了对象，而且不可逆 |
| **UR** | 研究发起人的判定标准："本来应该很简单的事情，甚至在理论 X 中都做不到" |
| **MinerU** | 本机文档解析工具，把 PDF/扫描件转成可检索可引用的 Markdown |
| **证据句定向核查** | 只对考古实际引用的句子做多管线比对，不做全文档 QA |
| **H** | 研究发起人命名的统一对象："数学家认为，引入 H 不会发生问题"——即宣布完成而不支付构造 |
| **LPO** | "每个无限搜索停没停，答案已经定了"；它是放弃 Q 的最简样子 |
| **Cantor 1882** | Russell 1914 认定的芝诺"解决"来源；不是 Cauchy 1821 |
