# 下一步具体怎么做

> 五条路线都可以独立开工，互不依赖。**都不自动启动**——要等研究发起人点头或明确条件满足。
> 每条都给：人话目标、第一步（小到一次会话能做完）、验收判据、预计成本、停止条件。

## 1. 芝诺史学层（建议优先级第一）

**人话目标**：回答"柯西为什么要严格化"。罗素侧有 Moore/Ferreirós/Hallett/Kanamori 四方位说
"Zermelo 的动机是良序优先"；芝诺侧一条都没有。补上之后，「极限理论解决了芝诺」的叙事
就有了和罗素包对称的史学层。

**为什么现在做最合适**：Z01 已经证明柯西全书不提芝诺，Z02 已经追到 Russell 1914 与 Cantor 1882。
中间那一跳（1821→1882，分析严格化）现在是空的。而柯西自己的 Introduction 已经逐字落盘，
他自陈动机是"rigueur"与"conditions de leur convergence"——这是现成的起点。

**第一步**（一次会话）：细读 `叙事源头/russell1914-gutenberg-37090.txt` 的 Lecture V–VII，
把 Russell 对 1821–1882 之间人物的每处提及（Bolzano、Weierstrass、Dedekind、Cantor）
做成带行号 locator 的清单；再去取 Bottazzini / Grattan-Guinness 的开放可及部分
（SEP 书目里已有条目，先核哪些有开放全文）。

**验收判据**：证据文件 `来源/Z03-*` 落盘，含 sha256、逐字引文、时间线；
每条引文经归属自检（这是这十天三次教训的直接应用）。

**预计成本**：1–2 次会话。主要风险是核心文献（Bottazzini）无开放全文，
若无则如实登记 `SOURCE_REPORTED_NOT_REPLAYED` 或改用 SEP/Grattan-Guinness 转述层。

**停止条件**：拿到"严格化的动机排序"（对应罗素侧"良序优先"）即可停；
不追"谁第一个说解决了芝诺"（那是需要证书的负结论，见分片 003 §3.2）。

## 2. 把 Russell 1914 接回 H 深化（建议优先级第二）

**人话目标**：H 深化文档现在只有机器证据和 AI 分析，缺历史锚。
Russell 1914 那句"逐点放行则芝诺为真"正好是「一侧问终局就够、一侧被迫问过程」的一手出处。
接上之后，H 的核心表述从"我们的分析"升级为"有 1914 年原文支撑的论述"。

**第一步**：在 `docs/H深化-*.md` 新增一节，逐字引 Russell 1914，明确三层分离：
〔发起人原话〕/〔一手文献〕/〔我们的分析〕。**不要**改 §2–§7 的既有论证
（那些是本轮新写的主体），只加历史锚一节。

**验收判据**：引文经字母流回验 + 归属自检；新增节不改变既有判词；
若你认为该升级 README §4，单独走 release 流程（等裁定 §1.2）。

**预计成本**：半次会话。

**停止条件**：一节写完即停。不要顺手把 H 的其它部分也重写。
