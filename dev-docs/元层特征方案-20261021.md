## 1. 回答：可以，而且第一步已经证出来了

**〔机器已证，C-438〕**

先把一个理论写成一个类型：元素是理论的对象，“相同”就用理论自己的“是不是同一个”。然后看那个被一次收齐的整体。

**一个理论暴露 A，当且仅当在它自己的“是不是同一个”之下，这个整体在任何有限层都不落定。**

- **不落定时**，两件事一起发生：
  - 逐层追问“是不是同一个”永远停不下来，这就是 B；
  - 在任何有限层宣布完成，都会换掉对象（C-436 的代价）。
- **在某一层落定时**，追问到那一层就停，在那一层宣布完成是免费的，A 看不出任何代价。

这个判据对任意类型都成立。下面是它的抽象程度为什么“恰当”。

- **不太抽象**：判据只看一样东西，即理论自己的“相同”有几层。对任何一个理论都能具体去查，不需要先把它变成 HoTT。
- **也不太具体**：ZFC、结构集合论、HoTT 用的是同一把尺子，量出来的结果正好对应“藏”与“暴露”。

## 2. 两边的特点

| | 极限理论（ZFC 的集合论语义） | HoTT |
|---|---|---|
| 理论自己的“相同” | 是事实：只有“是”或“不是” | 有结构：“以什么方式相同”，而且由单价性当真 |
| A：把所有有限阶段一次收齐 | 得到 ω，一个集合 | 得到有限层类型的全体：每一层都一次交出 |
| 追问“是不是同一个” | 第 1 问就停 | 永不停 |
| 宣布完成（只留下终局） | 免费：C-436 (4)；一阶一侧 C-437 | 在任何有限层都换掉对象：C-436 (3)、C-438 (5) |
| 研究发起人认可的说法 | “一侧问终局就够” | “一侧被迫问过程” |

**〔对应关系，是读法〕**“只问终局”与“被迫问过程”，在判据里各有落点：

- **只问终局**，就是相同是事实。过程（以什么方式到达）被商掉了，剩下的只有终局这一个值。C-436 证明：只留终局（在第 2 层宣布完成）不丢东西，当且仅当对象本来就是集合。
- **被迫问过程**，就是相同保留过程：两条不同的路径是两个不同的“相同”。这时 A 把所有层一次交出，过程就有无穷多层要回答。

**最干净的对照（`sameATwoFates`）**：同一个动作“把所有有限阶段一次收齐成一个现成的整体”。

- **在 ZFC 里**，得到 ω。追问第 1 问就停，完成免费。
- **在 HoTT 里**，得到有限层类型的全体：
  - 每一个成员都在某个有限层，每一个有限阶段的收集都会停；
  - 收齐之后的整体却永远问不完，内核跑 1000 步仍无答案。

**〔我们的分析〕**HoTT 一侧，没有一个成员是无穷的，问题只出在“一次收齐”这一步，也就是 A 本身。ZFC 一侧，同一步免费，所以看不见。这就是“数学家认为，引入H不会发生问题。但是H在HoTT中却表现出了问题”的一个精确形式。

## 3. 目标定理：理论只要满足这种形态，就一定暴露 A

**〔机器已证，C-438 (1)(2)〕**对任意收集 C（编码是理论的对象，成员是它们的意义）：

- **形态**：单价，并且所有高度一次交出（C-430 的两个成因）。
- **结论**：满足形态，就有
  - 每一个有限阶段的追问都停；
  - 整体的追问永不停，B 成立；
  - 在任何有限层宣布完成都保不住整体。
- **反面**：编码的相同是事实，则不管 A 在不在，第 1 问就停，完成免费，A 看不见。

所以研究发起人要的那个结论，在“高度”这条轴上已经是一条定理：

> **理论只要满足这种形态（它自己的“相同”有结构，而且一次收齐的整体带着所有高度），就一定暴露 A：B 在它里面成立，宣布完成在它里面要付代价。**

**还差什么**（照实）：

- **呈现是否忠实**：定理说的是“写成类型的呈现”。一个具体理论的呈现是不是忠实，要逐个论证。ZFC 用的是 HoTT Book §10.5 的累积层级 `V`，这是标准做法，但仍是读法。
- **只覆盖高度轴**：见 §5。

## 5. 另外两条轴（只记，不展开）

**〔我们的分析〕**判据量的是“相同有几层”（高度）。A 的代价还可能在另外两处露出来，repo 里各有现成的一块。

- **深度**：一层的“是不是同一个”，要无穷多步才答得完。例子是构造性分析里两个实数是否相等：只能逐个精度去核，永远核不完。
  - C-112 把这种问法写成通用的 ω 追问 `OmegaQ = ℕ → Bool`；
  - C-418 证明“每个单调追问都有落定的一步”等价于 LPO（不用选择公理）。
  - ZFC 用排中律一次答完，所以看不见。
- **大小**：哪些整体可以一次收齐。例子是罗素。C-437 (4) 是它在一阶里的影子：不先证存在就给东西起名，会证出 ⊥。ZFC 用分离公理限制收齐的范围，代价在这里付掉。

## 6. 归因（不推迟：《最高指示-Claude版》§1.3）

判据成立，但“HoTT 暴露了 ZFC+A 的问题”这句话要归因：到底该怪哪个前提？

- **候选前提**：
  - (a) A：一次收齐成现成的整体；
  - (b) HoTT 的单价性：把“相同”当成有结构的东西；
  - (c) 呈现方式：把一个理论写成一个类型。
- **能区分它们的证据**：
  - C-430 的消融：只有 A、相同是事实，第 1 问就停；只有单价性、高度有上限，也停。两条都要。这说明 (a)、(b) 单独都不够。
  - C-438 的阶段对照：同一个单价理论里，每个有限阶段都停，只有“一次收齐”之后才永不停。在单价性不变的前提下，变化只来自 A。
  - 2LTT（§4；2026-10-21 已证，C-442）：同一个理论里，外层宇宙与外层编号的相同全是事实（UIP），内层宇宙与内层的阶段汇集追问永不停。同一个理论、同一个 A，代价只在有结构的那一层出现。“代价来自理论本身”与“代价来自呈现方式”(c) 因此大大削弱：两层用的是同一种呈现，差别只在相同的种类。
- **我的判断**〔AI 判断，与裁定 D4“被告是 A，单价性是成因”一致〕：
  - 被告是 A；
  - 有结构的相同不是被告，而是让 A 的代价显形的探测器。HoTT 之所以能“暴露”，是因为它把“是不是同一个”当真；
  - ZFC 免费，是因为它的相同只有一层，代价无处可放，而不是代价不存在。C-437 证明：从 ZFC 内部看不出任何痕迹。

- 绕开的办法：不建一般的可纤性机制，把匹配对象（边界壳）直接写成内层类型，有限个面上的积用外层递归展开成内层的元组。于是对每个外层 n，前 n 层的半单纯类型全体是一个内层类型 `SST n`；取面的单位律与复合律是外层严格相等，对一切 n 证出；在具体的面上，这些相干的证明按定义就是 refl。思路是 Herbelin（2015）加外层 UIP，“对外层 n 构造前 n 层”是两层类型论论文（Annenkov–Capriotti–Kraus–Sattler）摘要里举的应用，不主张原创。
