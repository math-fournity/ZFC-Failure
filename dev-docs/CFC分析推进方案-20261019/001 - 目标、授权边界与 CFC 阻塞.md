`shard_contract`，机械保障有三层，缺一层都会在压缩后失效：

1. **本方案是 v2 shard index 逻辑文档**：canonical 路径 = 索引，正文 = 6 个 `NNN - 子主题.md`
   分片。`.codex/tools/cognition_runtime.py`（3.6.1）在加载链上强制"索引 + 按表顺序全部分片"

2. **必须登记为可发现的加载入口**：shard 结构本身不自动让任何 Session 找到它。
   下一动作 = 在 `README/001 - 当前入口与关键文件.md` §4 追加本方案入口（连同 Z03 证据文件），
   并把本方案写入 `MEMORY/001 - 当前执行队列.md` 的当前位置。
3. **TASK_ROUTING 不因本方案改路由**：本任务属"纯治理/机械背景"之外的**研究与考古**混合任务，
   角色为 `RESEARCH_GENERATION`；TASK_ROUTING 的"其它HoTT理论研究"行已经覆盖，
