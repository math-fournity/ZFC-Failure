### Z05 为什么值得单独一篇（对 goal 第 1、2 问都是一手最近点）

Russell 先说「计数在无穷上不可能、在有限上也不是逻辑根本」（R31），
再把**数定义为相似类之类的整体**（R33），最后写下最锋利的一句：

> R38「Numbers, in fact, must satisfy the formulae of arithmetic; **any indubitable set of objects
> fulfilling this requirement may be called numbers**.」

〔我们的分析〕：这是**用「满足要求」替换「是什么」**的一手范例——
与 H 深化 §2 对象层「完成必须有承载、承载可被替换」同构。
而且 Russell **本人坦身写了代价**（R35「a feeling of oddity」、R36「The answer to a feeling
cannot be a logical argument」），只是判定它不重要。
**这与"没人发现"不是一回事**：它是"早已写下并主动判定代价不重要"的一手证据。

### C-437 侦察结论（工程级，非命题）

1. **Lean core 够承接实例级与定义展开级**：`cast p b = b` 是 `rfl`，完成型命名可判定为
   定义展开，两者**零公理依赖**。
2. **Lean core 不够承接"保守扩张"一般定理**：那是**跨语义**全称陈述
   （`∀ L-句 φ, M ⊧ φ ↔ M' ⊧ φ`），需要 core 不提供的语义对象 → 必须模型论层。
3. **一次如实失败留档**：第一版 toy 写 `Nat -> Rat`，bare core 没有 `Rat`。
   **这个失败本身有信息**：连"级数的和"这个最裸 toy 都需要一个稠密目标类型，
   而 core 只给 Nat/Bool 与自定义结构——即"极限侧完成 = 命名"的最低玩具模型
   在 core 层就要先建一个稠密对象。改用 `Nat -> Bool` 后 exit 0。

### 第二例同型假阴性（比 A4 本身更值得记住）
