# 既有地基与四段一手材料

## 1. C-112 图式的精确类型（侦察的起点）

`HoTT/formal/claude-cg001/same-q-univalent/SameQ.agda` 已定义的、与"读法"直接相关的类型
（行号经 `rg` 取得，可核）：

| 名字 | 定义（照源码） | 行 | 它是什么 |
|---|---|---|---|
| `OmegaQ` | —（来自 `QuestioningDelay`） | 71 | 一个 ω 追问 = 逐阶段问真假、答真即停的程序 |
| `NeverFrom q s` | `(k : ℕ) → q (k + s) ≡ false` | 96 | 从第 s 阶段起永不落定 |
| `Never q` | `(k : ℕ) → q k ≡ false` | 100 | 从不落定 |
| `Arrives q` | `(K : ℕ) → Σ[ n ∈ ℕ ] K ≤ halvings q n` | 176 | **跑者到达**：对每个精度 `2^-K`，剩余距离终将不超过它 |
| `halvings q n` | 减半次数（源码另有 `halvingsNever`/`halvingsStep`） | 202–204 | 剩余距离的算术写法 |

**关键观察（侦察的第一个实质发现）**：`Arrives` 与 `Never` 在 C-112 里
**已经是两个独立的类型**，并且 C-112 (d) 证明了二者在**单调前提**下等价：

- `arrivesOfNever : Never q → Arrives q`
- `neverOfArrives : (单调 q) → Arrives q → Never q`
- `monotoneNeeded`：单调前提不能去（交替追问的跑者到达，追问却第 0 阶段就落定）

**这意味着**：`H深化` §4.1 说的"终局读法 vs 过程读法"**不是**两个需要新发明的概念，
它们在 repo 里已经是 `Arrives` 与 `Never`。C-439 要形式化的"分离条件"
因此可以表述为：**`arrivesOfNever` 与 `neverOfArrives` 成立的确切前提组合**。

## 2. 本轮新增的四段亚里士多德原文（语义锚）

来自 `docs/芝诺解决考古/希腊原文层版本与全处定位-20261019.md`（Ross 校本 + Bekker 参照）：

| Bekker | 类型层对应 | 原文关键片段 |
|---|---|---|
| **233a–233b**（二分判词） | `Arrives` 侧 | 「τῶν δὲ κατὰ διαίρεσιν ἐνδέχεται· καὶ γὰρ αὐτὸς ὁ χρόνος οὕτως ἄπειρος」 |
| **239b–240a**（飞矢判词） | `Never` 侧 + 分层被否定 | 「οὐ γὰρ σύγκειται ὁ χρόνος ἐκ τῶν νῦν τῶν ἀδιαιρέτων」 |
| **250a–250b**（谷粒判词） | 整体 vs 逐个 | 「οὐδὲν γὰρ κωλύει μὴ κινεῖν τὸν ἀέρα ἐν μηθενὶ χρόνῳ」 |
| **263a–263b**（计数化版本） | **ASK 被显式要求并驳回** | 「ἀριθμεῖν καθʼ ἕκαστον γιγνόμενον τὸ ἥμισυ」 |

**263a 是侦察中最重要的语义锚**：亚里士多德把二分改写成一个**逐个计数任务**，
并因其"会数了一个无穷的数"而驳回。这正是把 `Never`（过程面）从
`Arrives`（终局面）**分离出去**的那个动作的古代显式版本。

**注意（分层纪律）**：这四段是**一手文献的语义锚**，不是 HoTT/Agda 里的定义。
它们的作用是说明"为什么值得形式化这个分离"，**不是**形式化的前提。
C-439 若立项，其命题必须在 Agda/Lean 里自洽，不能引用希腊原文当公理。

## 3. 侦察中被自己否定的两个初始签名想法

侦察一开始我写了两个看似自然的签名，都在这一步被否。如实记录：

### 3.1 否定一：把"读法"做成 `OmegaQ` 上的一个参数

最初想法：`Reading : Type` 两个构造子 `Terminal` / `Process`，
然后问 `Arrives`/`Never` 各自在哪个 reading 下有定义。

**为什么否**：这会把"读法"变成一个**可自由选择的模态**，
从而可以写出"选 terminal 读法就看不到 Never"这类命题——
但 C-112 的铁证是 `monotoneNeeded`：**交替追问**的跑者到达、追问却第 0 阶段落定。
也就是说"选读法"本身不能保证分离；**分离依赖追问自身的单调性，不依赖谁去读**。
一个自由 reading 参数会把依赖关系放错位置，得出的"分离"是假的。

### 3.2 否定二：把"检测义务"做成类型上的一个 `Bool` 字段

最初想法：给追问类型加一个 `obligation : Bool`，`true` = 必须回答每层。

**为什么否**：这正是 `H深化` §6 触发句里点名的"**可以加一个字段**"反应。
加字段能写出命题，但它**没有回答**理论原先为何没有这个字段；
加回去之后同一理论收益是否仍在，也未回答。写成 `Bool` 字段会把这个未回答的问题
藏进一个构造子里。**若要保留"义务"这一维，它必须从追问的语义导出，不能是自由参数。**
