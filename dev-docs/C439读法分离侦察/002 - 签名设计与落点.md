### 5.1 顺带发现的一个不对称（对 `H深化` §4.1 的实质补充）

`arrivesOfNever`（:211）**不需要** `Monotone q`；`neverOfArrives`（:234）**需要**，
且 `monotoneNeeded`（:264-266）证明该前提不可去（反例 `alt`：`true, false, true, …`，
跑者到达但第 0 阶段就落定）。

因此：

- 「**永不停** ⟹ 跑者到达」是**无条件定理**；
- 「跑者到达 ⟹ **永不停**」是**条件定理**，且条件不可去。

**所以「读法分离」是单向的，不是对称分离。** `H深化` §4.1 写「两面在单调条件下等价」
在类型层正确，但**方向成本不对称**这一点在文字里没体现；写成「分离」易被读成对称。
下一轮若推进 `H深化`，应把这一点补进去——这是本轮侦察对既有文档的实质增量。
