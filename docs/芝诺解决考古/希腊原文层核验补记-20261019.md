## 3. 为什么"不存在"不等于"亚里士多德没写过"

这一条必须写清楚，否则负面结论会被误用：

1. **本卷 OCR 质量差**：多音调符号系统性丢失（`λόγον`→`λύγον`、`ἀμερές`→`ὠμερές`）、
   两栏混排、apparatus criticus 混入正文、无 Bekker 页码标记。基于内容的检索在此不可靠。
2. **本卷的著作品顺序与内容判定靠 anchor + 词汇**，未核对目录页；因此"Physics VI 到此结束"
   是**由 Meteorologica 章题反推**，不是由卷首目录确认。
3. **A3/A4 归属的 Bekker 位置本身来自 Fairbanks 的标注**，而 Fairbanks 的编号已被证明
   至少错一次（见核验记录 §2.2）。所以"A3 属 VI.9 239b5"这个前提本身也未确认。

**因此本轮只能宣布**：
在本卷 OCR 的可核区间内，用给定记号未检到 A2/A3 的对应希腊文本。
**不能宣布**：亚里士多德没有这些判词、或 Fairbanks 的引文是伪造的。

## 4. 处置与下一步

- **A2/A3/A4 保持转录层**（不得引用希腊页码）。这是上一轮已定的规则，本轮不改变。
- **不要把本轮负面结果写成"找不到所以没有"**。它是"本卷 OCR 内未检到"，
  检索面受限（单一 OCR 文本 + 内容检索 + 无页码）。
- **若要真正确认，唯一可靠路径**（需研究发起人决定是否投工）：
