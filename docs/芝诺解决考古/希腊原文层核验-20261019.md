## 2. 定位到的希腊原文（Physics VI.2，章题 "ΠΕΡΙ ΑΤΟΜΩΝ ΓΡΑΜΜΩN"）

OCR 无 Bekker 页码标记，故按**章题 + 句子内容**双重定位。章题
`ΠΕΡΙ ΑΤΟΜΩΝ ΓΡΑΜΜΩΝ` 即 Physics **VI.2**（论不可分线），地理位置正确。

### 2.1 成功核到的一句（A1 的对应物，233a21–23）

> 「τὸν Ζήνωνος λόγον ἀνάγκη τι μέγεθος ἀμερὲς εἶναι, εἴπερ ὑδεμία τῶν νῦν δὴ εἰρημένων…」

（OCR 原文，多音调符号在该扫描中丢失：`λύγον`=λόγον、`ὠμερὲς`=ἀμερές、`ὑδεμίω`=ὑδεμία、
`ὠλλήλας`=ἀλλήλας。）

**〔核验结论〕**：这一句的希腊原文**确实**说"按 Zeno 的论证，必然有某个大小（magnitude）是
不可分的"——它是 Aristotle 在 VI.2 提出的**第三个论证**（针对无理线），
不是 Fairbanks 标注为 `Phys. vi. 2; 233 a 21` 的那句**判词**。

### 2.2 Fairbanks 编号定位有错（必须更正）

补遗里的 A1 引的是 *"Zeno's argument is erroneous, that it is not possible to traverse
infinite spaces…"*，Fairbanks 把它标为 `Phys. vi. 2; 233 a 21`。**这个编号对不上**：

- 233a21–23 的希腊原文是 §2.1 那个"必然有某个大小不可分"的**论证句**，不是**判词句**；
- "traverse infinite spaces … in a finite time" 的判词属于 Physics **VI.2 的后段**
  （233b 附近，Bekker `232b–233a` 交错区），Fairbanks 的引用串了位置。

**处置**：补遗 §2.1 的 A1 保留（它是 Fairbanks 译本的忠实转录，英文层无误），
但**加注**：其 Bekker 编号引自 Fairbanks 的标注，本文未能在希腊原文中确认该编号指向判词句。
**在引用 A1 带 Bekker 页码时，必须说明这一未确认状态。**

## 3. 本文能支持什么、不能支持什么

**能**：Fairbanks 1898 是一部真实存在、可公开取得的转译本；其 VI.2 相关段落与 Bekker
希腊原文在已核的那一句上一致；补遗 A1–A4 的**英文转录层**身份保持有效。

**不能**：
1. **不能**说 A2/A3/A4 已在希腊原文层确认——都没有。
2. **不能**再把 A1 的 Bekker 编号当已核事实。
3. **不能**宣称完成了"核希腊文原刊"这一未闭合项——只完成了一部分。
