## 4. 复跑

~~~bash
git ls-files "*.pdf" | while read f; do pdfinfo "$f" 2>/dev/null | grep -E "^(Title|Author|Producer)"; done
git ls-files "*.pdf" -z | xargs -0 sha256sum | sort | uniq -w16 -D   # 找重复
git ls-tree -r --name-only origin/dev | grep -i "\.pdf$"             # 已发布集
git diff --numstat origin/dev..dev | awk '$1=="-"{print $3}' | grep -i pdf  # 本次新发布集
~~~

分类判据（渠道 > 年份 > 文件名）与逐件结果在会话记录与本报告 §1；
哈希去重把 84 路径归并为 65 文档是本报告口径的基础。
